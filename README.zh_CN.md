# 音乐电台 —— 三键小机器上的蜻蜓 FM 纯音乐台

装在 FoloToy AI Passport 上的**纯音乐**网络收音机，台源来自
**[蜻蜓 FM](https://www.qtfm.cn/)**（国内最大的网络电台平台之一）：18 个精选
全音乐台——上海动感101、LoveRadio、AsiaFM 家族、经典怀旧、各省市音乐广播
——按**流行 / 经典 / 亚洲 / 省市**四个分组循环。每个台都经过纯 http GET
实收字节验证才烧进固件。

上下键调台、OK 播放暂停、长按上下调音量。复古刻度盘配滑动指针——
**霓虹靛紫**主题，家族电台三连的第三张皮肤（琥珀「网络电台」、中国红
「央广播音机」、这一台「音乐电台」）。

| 标题页 | 收音机主页 | 音量浮层 |
| --- | --- | --- |
| 铭牌、联网状态、装饰刻度带。 | 刻度盘 + 指针、台名、实时状态与码率、播放中跳动的调谐条。 | 长按上下出现，1.6 秒自动消隐。 |

## 台单

| 分组 | 电台 |

| 流行 | 动感101、LoveRadio、动听音乐台、星河音乐、清晨音乐台 |

| 亚洲 | AsiaFM HD、亚洲天空台、亚洲粤语台、亚洲经典台 |
| 省市 | 广东音乐之声、顺德音乐之声、怀集音乐之声、苏州音乐广播、河北音乐广播、哈尔滨音乐广播 |

直播流为纯 http MP3（`lhttp.qtfm.cn/live/{id}/64k.mp3`）——与兄弟应用同源、
两代真机验证过的管线，无 PSRAM 的芯片不需要 TLS。台单在 `main/mr_station.c`；
改台名后用 `tools/music-radio/gen_font.py` 重新生成中文字库。

## 快速上手

1. 首次使用：标题页 → 长按确定 → 手机连设备热点 **MusicRadio** → 访问
   192.168.4.1 输入家里 Wi-Fi（2.4G）→ 设备自动联网并记住。
2. **OK** 进收音机页，再按 **OK** 播放；上下键在四个分组间循环换台；长按
   上/下调音量（0–100 共 10 档）。
3. 播放中再按 OK 暂停；长按确定回标题页并停播。上次电台与音量断电记忆。

## 构建

[ESP-IDF](https://github.com/espressif/esp-idf) 5.5.3 工程，目标 FoloToy AI
Passport（ESP32-C3，240x320 ST7789，三键 ADC 输入，ES8311 音频）。

```bash
idf.py build
idf.py flash monitor
./tools/validate.sh
```
